## 摘要
预测多样化的未来状态是视频世界建模中的核心挑战。判别式世界模型产生确定性的预测，这在隐式上对可能的未来进行了平均，而现有的生成式世界模型计算成本依然高昂。最近的研究表明，在视觉基座模型（VFM）的特征空间中预测未来，而非在针对像素重建优化的潜空间中进行预测，所需的模型参数显著减少。然而，大多数此类方法仍属于判别式。在这项工作中，我们引入了 DeltaTok（一种将相邻帧之间的 VFM 特征差异编码为单个连续“delta”token 的分词器）以及 DeltaWorld（一种在这些 token 上运行的生成式世界模型，用于高效生成多样且合理的未来）。Delta token 将视频从三维时空表示简化为一维时间序列，例如在 512x512 分辨率的帧下，可实现 1,024 倍的 token 缩减。这种紧凑的表示使得可处理的多假设训练（multi-hypothesis training）成为可能，即并行生成多个未来，且仅对最佳结果进行监督。在推理阶段，这使得在单次前向传播中即可产生多样化的预测。在密集预测任务上的实验表明，DeltaWorld 预测的未来与真实世界的结果更加一致，同时其参数量比现有生成式世界模型少 35 倍以上，FLOPs 消耗减少了 2,000 倍。代码和权重：https://deltatok.github.io。

## Abstract
Anticipating diverse future states is a central challenge in video world modeling. Discriminative world models produce a deterministic prediction that implicitly averages over possible futures, while existing generative world models remain computationally expensive. Recent work demonstrates that predicting the future in the feature space of a vision foundation model (VFM), rather than a latent space optimized for pixel reconstruction, requires significantly fewer world model parameters. However, most such approaches remain discriminative. In this work, we introduce DeltaTok, a tokenizer that encodes the VFM feature difference between consecutive frames into a single continuous "delta" token, and DeltaWorld, a generative world model operating on these tokens to efficiently generate diverse plausible futures. Delta tokens reduce video from a three-dimensional spatio-temporal representation to a one-dimensional temporal sequence, for example yielding a 1,024x token reduction with 512x512 frames. This compact representation enables tractable multi-hypothesis training, where many futures are generated in parallel and only the best is supervised. At inference, this leads to diverse predictions in a single forward pass. Experiments on dense forecasting tasks demonstrate that DeltaWorld forecasts futures that more closely align with real-world outcomes, while having over 35x fewer parameters and using 2,000x fewer FLOPs than existing generative world models. Code and weights: https://deltatok.github.io.

*   **研究动机**：视频序列中相邻帧之间存在极大的时空冗余。作者认为，与其预测完整的图像或特征图，不如只预测帧与帧之间的“变化”。
*   **核心目标**：开发一种既能像判别式模型一样高效（单次前向传播），又能像生成式模型一样产生多样化、高质量未来的世界模型。

### 2. 论文提出的方法论
该论文提出了 **DeltaWorld** 框架，由两个核心组件组成：
*   **DeltaTok（增量分词器）**：
    *   **核心思想**：利用视觉基座模型（VFM，如 DINOv3）的特征空间，将当前帧与前一帧的特征差异压缩进**单个连续的“增量（Delta）”Token** 中。
    *   **技术细节**：采用连续自动编码器结构。编码器输入当前帧和前一帧的特征图，输出一个 D 维向量（Delta Token）；解码器则根据前一帧特征和该 Token 重建当前帧特征。
    *   **压缩率**：在 512x512 分辨率下，将原本 1024 个空间 Token 压缩为 1 个，实现了 1024 倍的序列长度缩减。
*   **DeltaWorld（生成式预测器）**：
    *   **核心思想**：在 Delta Token 空间内进行自回归预测。
    *   **多假设训练（Best-of-Many, BoM）**：为了实现生成能力，模型输入随机噪声查询（Noise Queries）。训练时并行生成 $K$ 个候选未来，仅对与真实值最接近（L1 距离最小）的那个预测分支进行梯度更新。
    *   **推理流程**：在推理时，只需更换随机噪声，即可在单次前向传播中生成多个不同的未来路径。

### 6. 主要结论与发现
*   **一帧即一 Token 是可行的**：通过 Delta 编码，单个 Token 足以捕捉帧间动态，极大地简化了视频建模复杂度。
*   **性能超越巨型模型**：尽管参数量极小，DeltaWorld 在预测准确度上依然超越了计算成本高出数千倍的 Cosmos 模型。

### 7. 优点（亮点）
*   **极高的计算效率**：将视频从三维时空张量简化为一维时间序列，使生成式世界模型在边缘设备上的实时运行成为可能。
*   **优雅的生成机制**：通过 BoM 目标规避了扩散模型复杂的迭代采样过程，实现了单次前向传播生成多样化未来。
*   **强大的泛化能力**：在未见过的评估数据集上表现稳健，证明了基于 VFM 特征空间建模的优越性。

### 8. 不足与局限
*   **分布建模精度**：BoM 目标虽然能产生多样性，但缺乏像扩散模型那样严格的概率分布保证，可能无法完美覆盖所有极端长尾情况。
*   **误差累积风险**：由于 Delta 编码依赖于前一帧的重建，在长程自回归生成中，微小的重建误差可能会随时间步累积，导致特征漂移。
*   **应用限制**：目前主要在特征空间运行，若需生成人类可读的高质量像素视频，仍需额外的解码器（如 RAE），这会增加额外的开销。
